Security

Security at WANDERCOIL.

How to get our software safely, and how to tell us privately if you find a problem.

  1. DOWNLOAD SAFELY

    Use official sources only

    Download Lens It only from wandercoil.github.io/lensit or our official releases page. Each release lists its SHA-256 checksum so you can confirm the file is genuine.

  2. BUILT-IN CHECKS

    Tampered files are refused

    Lens It checks its packages and AI models during setup and refuses anything that doesn't match. If a check fails, stop, delete the folder and download it again from the links above.

  3. REPORT A PROBLEM

    Tell us privately

    Found a vulnerability? Report it privately so it can be fixed before anyone else learns of it. Please don't post it publicly.

Private report

Reports go straight to the team through GitHub's private vulnerability reporting.
