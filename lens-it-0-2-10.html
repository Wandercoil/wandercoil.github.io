Lens It 0.2.10 released.

A security and privacy update for photographers. We recommend everyone using Lens It updates.

What changed

  1. 01

    Selfies stay in memory

    Large selfies could briefly be written to a temporary file on the laptop. Every selfie is now kept in memory only and discarded after matching.

  2. 02

    Upload and search limits

    Selfies over 15 MB are refused, and each phone can run a limited number of searches in a short time, so one device can't overload the event laptop.

  3. 03

    Protected setup screens

    The photographer's setup screens now refuse requests from other websites open on the same laptop.

  4. 04

    Updated packages

    All software packages are updated, with no known vulnerabilities when checked at release.

  5. 05

    Setup checklist

    A before-the-event checklist and a draft guest notice the photographer can copy, to help tell guests about face matching.
